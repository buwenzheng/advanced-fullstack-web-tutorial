| 路径 | 结业声明（学员可见一句话） | 证明物（项目） | 里程碑 ID 列表（数据中真实存在） | 明确不要求 |
| --- | --- | --- | --- | --- |
| A 后端补齐 | 能独立交付可上线、可观测且可回滚的 API。 | `p-m2-api` + `p-m3-ship` | `p-m2-api-m1`, `p-m2-api-m2`, `p-m2-api-m3`, `p-m2-api-m4`, `p-m2-api-m5`; `p-m3-ship-m1`, `p-m3-ship-m2`, `p-m3-ship-m3`, `p-m3-ship-m4`, `p-m3-ship-m5`, `p-m3-ship-m6`, `p-m3-ship-m7`, `p-m3-ship-m8`, `p-m3-ship-m9`, `p-m3-ship-m10` | E1、`p-m3-web`、X、M4、真机/VPS 部署 |

| C AI 全栈 | 能交付可评估、可降级、可安全协作的 AI 全栈产品。 | 路径 B 证明物 + `p-m4-ai` | 路径 B 全部；`p-m4-ai-m1`, `p-m4-ai-m2`, `p-m4-ai-m3`, `p-m4-ai-m4`, `p-m4-ai-m5`, `p-m4-ai-m6`, `p-m4-ai-m7`（其中 `p-m4-ai-m7` 含 M4-Coding 协作记录门槛） | E1、X |

## X 规划编号到数据 ID

毕业项目当前保留可恢复的 `m1`～`m11` 数据 ID；规划 X1～X10 与数据的对应关系如下，避免 R4 自行推导：

| 规划里程碑 | 数据里程碑 ID |
| --- | --- |
| X1 契约与认证 | `m1` |
| X2 核心链路 | `m2` |
| X3 缓存与保护 | `m4` |
| X4 异步统计 | `m3` |
| X5 可观测与交付 | `m5`、`m6` |
| X6 Web 与 BFF | `m7` |
| X7 质量门槛 | `m8` |
| X8 多租户后台 | `m9` |
| X9 AI（可选档） | `m10` |
| X10 答辩 | `m11` |

## 三档结业

- 全栈：`m1`～`m9` + `m11`；`m3` 可采用 M3 应用内异步方案。
- AI 全栈：全栈档 + `m10`。
- 分布式：全栈档，且 `m3` 必须采用 E1 的 Outbox、独立消费者与可重建读模型方案。
