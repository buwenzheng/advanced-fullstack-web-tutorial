## 3. 代码题

### s7-l1 SSE 解析 + 流式网关（10 条）

1. 单块 SSE 派发一个事件。
2. 跨块切断仍能拼出完整 data：`['data: he', 'llo\n', '\n']`。
3. 多行 data 以换行拼接：`first\nsecond`。
4. CRLF、`id:` 与注释行 `: keep-alive`。
5. `[DONE]` 输出 `{ event: 'done', data: '' }`。
6. 低复杂度走 cheap，并按输入/输出 token 计费。
7. 高风险升级到 strong 并计算成本。
8. 超出预算抛出 `BUDGET_EXCEEDED` 且不重试。
9. 带幂等键的可重试错误重试一次后成功。
10. 非幂等请求失败不重试。

计费用整数分累加，避免浮点误差；mock 错误固定为 `RATE_LIMITED`、`TIMEOUT`、`INVALID_JSON`，其中前两者可重试、第三者不可重试。

### s7-l2 切分 + 混合检索 + 受限工具（13 条）

- 切分：不产生空块、索引连续、重叠小于 maxChars、块末落在句子边界。
- 检索顺序：租户过滤发生在补齐 embedding 与排序之前；测试断言 `embed` 从未收到其他租户文本，且结果不含 `x1-*`。
- 引用：新增「引用精确到文档块」用例，逐条断言 `citation` 精确等于来源的 `{ docId, chunkIndex }`，并断言键集合恰为 `chunkIndex,docId`，只有文档 id 的实现会失败。
- 排序：向量与关键词分别 min-max 归一化后加权；同分按更新时间降序、再按 id 升序；topK 在排序后截断；空查询返回空数组。
- 工具：未知指标、超出时间范围、超出限行、跨租户均在查询前拒绝，测试断言 `query` 调用次数为 0；维度不一致抛 `DIM_MISMATCH`。
