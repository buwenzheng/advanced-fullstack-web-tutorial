## 3. p7 步骤与里程碑

p7 目标：只给 p2-p6 的既有能力加模型层与质量门，不重写已有产品；每项 AI 功能都有阈值、有降级、有审计。技术栈：LLM API、pgvector、SSE、OpenTelemetry。

8 个步骤：

1. 在 p3/p5 异步链路上加摘要与标签，创建短链只入队不等待，失败按降级返回空标签。
2. 复用 p5 的 Postgres 与 pgvector 建块级索引，租户过滤在相似度排序之前，引用精确到 `docId` 与 `chunkIndex`。
3. 注册受限问数工具：工具白名单、租户校验、字段白名单、行数与范围上限，禁止任意 SQL。
4. 实现 SSE：可取消、超时断开、按事件 id 重连补拉，重复事件只计一次。
5. 评估集与阈值接入 CI：事实、引用、拒答、直接/间接注入、成本降级，回归下降即失败。
6. 补齐安全与成本边界：间接注入不越权、跨租户全拒、PII 脱敏、单请求与租户双预算、模型故障降级。
7. 网关调用指标接入 trace，整理 AI 协作记录：至少 3 个失败案例，含一次完整回滚或重做。
8. 对照 p2-p6 做回归：AI 层关闭时产品行为与之前一致。

7 个里程碑，每个 3 条验收：

| 里程碑 | 验收要点 |
| --- | --- |
| m1 摘要与标签 | 创建接口 P95 不受模型延迟影响；任务可重试；失败不阻塞主流程 |
| m2 语义搜索与引用 | 租户过滤在排序前；引用精确到块；跨租户文档不进入候选集 |
| m3 受限问数工具 | 不直连生产库、不生成任意 SQL；跨租户与超限在查询前被拒绝并审计 |
| m4 流式输出 | 客户端可取消；超时释放连接；重连按事件 id 去重且缺口可补拉 |
| m5 评估与 CI | 任一指标低于阈值即失败；失败输出 caseId 与失败码；空评估集不算通过 |
| m6 安全与成本 | 注入不越权不泄密；跨租户全拒；超预算降级或排队；模型故障规则兜底 |
| m7 可观测与协作记录 | 能从 trace 定位一次失败调用；协作记录含现象、根因、修复与验证证据 |

9 项交付物：LLM 网关与预算表、摘要/标签异步任务（复用 p3/p5 队列）、语义搜索与块级引用（pgvector）、问数工具契约与审计记录、SSE 接口（取消/超时/重连）、评估集与 CI 报告、注入测试集与安全清单、成本上限与降级预案、AI 协作记录（≥3 失败案例，含一次回滚/重做）。

9 条清单与验收逐条对应，额外约束「AI 层关闭后产品回归一致」。3 个 stretch：语义缓存、多模型 A/B、只读分析型 Agent 工作流。

## 4. 项目检查

- **只加产品层**：步骤 1、2 明确复用 p3/p5 队列与 p5 的 Postgres/pgvector；步骤 8 要求 AI 层关闭后与 p2-p6 行为一致；清单第 1 条写死「不重写产品行为」。
- **m1 异步**：创建只入队，P95 不受模型延迟影响，失败返回空标签并记录原因；重试与降级写入验收。
- **m2 复用存储**：不新建向量库；块级切分、混合检索、租户过滤前置、引用到块均有验收与测试对照（s7-l2 的 13 条测试）。
- **m3 受限工具**：问数只调固定工具，不直连生产库、不生成任意 SQL；跨租户与超限在查询前拒绝并审计（s7-l3 的 11 条测试）。
- **m4 流式**：取消、超时释放、重连去重与缺口补拉；与 s7-l1 的 SSE 解析、网关预算测试口径一致。
- **m5 评估进 CI**：六类用例与四项指标阈值；空评估集不算通过；失败输出 caseId 与失败码（s7-l3 的评估测试）。
- **m6 安全与成本**：8 条工具注入用例全拒、6 条文本注入由拒答覆盖；PII 脱敏；双预算与故障降级。
- **m7 可观测与协作**：调用指标进 trace，能从 trace 定位失败调用；协作记录要求现象、根因、修复与验证证据，且含一次回滚/重做。

## 7. 残余风险

- p7 的交付物由学员按步骤产出，仓库只提供可执行文案；本报告核对步骤、里程碑、交付物与验收标准的一致性，不对未产出的学员代码做伪造验收。
- M1-M5 成熟度为自评工具，不是认证；正文已限定其用途与进入条件。
- 协作记录的「≥3 失败案例」依赖学员真实过程，无法在静态内容中验证；以 m7 验收字段与交付物约束保证可检查。
