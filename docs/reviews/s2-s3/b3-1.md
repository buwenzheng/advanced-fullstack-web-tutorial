## 3. 本轮发现与修复

1. JS 判题沙箱没有 `URL` 全局，`new URL` 抛 `ReferenceError` 被误判为 `invalid_url`。校验器与正文改为正则解析绝对 URL，规格同步改为「带主机名的绝对 URL」，不再依赖运行时全局。
2. 模板字符串中的正则反斜杠被吞掉：`\/\/` 变成 `///`、`\s` 变成 `s`，导致 solution 解析失败。已在代码块与 solution 中写成 `\\/\\/`、`\\s`，并复跑通过。
3. 正文校验器初稿漏掉 `title` 规则，与规则表不一致；已补 `trim` 后 1-120 字符校验。

## 5. 残余风险

- `Sunset` 与 `Deprecation` 响应头的支持程度取决于客户端与网关，正文只作为弃用流程的辅助手段，不承诺所有调用方都能自动识别。
- 路由匹配器是教学实现，未覆盖通配符、静态段优先与大小写策略；正文 note 已声明边界。
- 400 与 422 的选择在正文中要求全站固定，但项目实现尚未落地，需在 p2 契约测试中统一。
