## 2. 内容要点

- 终端类比为后端 DevTools；进程/PID/父子关系、退出码、TERM/INT/KILL/HUP；
- 端口占用五步排查、环境变量与配置优先级、DNS/hosts 排查、requestId 日志检索；
- `kill -9` 的坑块覆盖现象、原因、发现方式、修复与预防；
- 深挖块解释 fd、`ulimit`、TIME_WAIT 与临时端口，明确「取决于操作系统与配置」；
- p0 明确是独立排障工具，不是 LinkHub 的 API；p0-m1..m5 覆盖请求方法、分段耗时、错误分类、JSON 输出与自动化测试；
- p0 验收证据要求与 s0-l1/s0-l2 的代码题输出结构对齐，但不复用 API 语义。
