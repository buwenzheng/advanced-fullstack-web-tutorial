## 5. 本轮发现与修复

1. Python 测试里的任务工厂写成了 `async def make(...)`，返回的是 coroutine 而不是可调用任务函数，导致 `await tasks[index]()` 失败。改为普通 `def make(...)` 后 6/6 通过。
2. `s0-l2` Python 测试草稿里重复定义了一次 `flush`，已删除重复段。
3. 事实检查新增 HTTP/1.1、301/302 与 40×30ms 推导值的登记，避免正文数字成为未登记事实。

## 6. 残余风险

- 浏览器内 Pyodide 版本与本地 Python 3.11 的个别行为差异仍需在 G1 用站点实际运行时验证；
- `analyzeTimings` 的 Python `round` 使用银行家舍入，测试数据已避开 `.05` 边界，但正文外的学员数据仍可能出现两轨差异，已在代码块 note 中提示；
- 事件循环顶层 `setTimeout`/`setImmediate` 顺序不做断言，避免把实现细节写成规范。
