## 4. 问题与修复

- 首跑 budget FAIL：search-index-BwozhHnn.js（194.7KB）被计入懒加载 JS 上限。依据 §6.3「CSS 与 JSON 不计入 JS chunk」与 §6.1 搜索索引单列 300KB，将 search-index 从 lazy 预算剔除并单列计量；预算数字未调整。
- 首跑 lazy e2e FAIL：首页请求 catalog-DALFsimK.js 不在入口闭包。根因为 loadCatalog() 使用动态 import；与 §6.5「首页只请求入口闭包」冲突。将 web/scripts/app/data/resources.ts 中 catalog 改为静态 import 纳入入口闭包（entry 133.3KB → 147.8KB，仍 < 180KB；阶段内容与搜索索引仍按需加载）。修复后 lazy/search 2/2、完整 content.spec 9/9 通过。

## 5. 残余风险

- entry 闭包余量 32.2KB；后续新增入口静态依赖需复跑 npm run budget。
- 网络断言依赖哈希文件名与 manifest，构建后文件名变化不影响断言（比较 basename 集合）。
