视觉基线重采样与 diff 审阅（T-E4.4，2026-11-10）
====================================================

背景
----
T-E4.3 修复 axe color-contrast：课时代码注释 .tok-com 由 #5A6B87 改为 --code-comment: #7689A6（黑底对比度 3.23:1 → 4.91:1）。
该 token 同时作用于 v2 与 React 入口。旧基线仍含 #5A6B87。

关键发现：默认 update 模式不会重写基线
------------------------------------
命令（默认 --update-snapshots=changed）：
  npx playwright test e2e/visual.spec.ts --project=chromium -g "lesson-s0-l1|lesson-s7-l5" --update-snapshots
结果：6 passed，exit 0，但 6 张基线 mtime 未变、旧/新逐像素零差异。
原因：Playwright/pixelmatch 默认逐像素颜色阈值 0.2，注释色 #5A6B87 → #7689A6 的单像素色差
低于该阈值，测试被视为通过，快照不被认定为 changed，因此不落盘。
这正说明旧基线的“绿灯”不能证明基线已冻结当前渲染。

实际重采样命令
--------------
  npx playwright test e2e/visual.spec.ts --project=chromium -g "lesson-s0-l1|lesson-s7-l5" --update-snapshots=all
输出（节选）：
  ...\e2e\__screenshots__\lesson-s0-l1-1440x900.png is re-generated, writing actual.
  ...（6 张均 re-generated，其中 lesson-s7-l5 重写后字节相同）
  6 passed (4.5s)
退出码：0
