## 3. 本轮发现与修复

1. `s4-l1` 的一条测试名为「空直方图返回零值」，实际断言的是单样本分位与未注册指标，名实不符。已改名为「单样本分位与未注册指标」，Python 轨使用同一测试名。
2. `s4-l1` 的 Python 指标注册表代码块调用 `copy.deepcopy` 却漏了 `import copy`，已补齐；该块属于展示代码，不经过判题器，仍需能直接运行。
3. `s4-perf` 代码题 starter 故意保留「平均值代替分位、错误率恒为 0、并发恒为 0、不校验时长」，在 7 条测试中失败；solution 与 Python solution 全部通过。
4. 压测方法没有滑向排队论：深挖块只解释利用率与等待时间的非线性关系，公式推导与容量模型留给附录 a7；正文明确「Little 定律只用于平均值估算，不预测 P99」。

## 4. 边界与对齐检查

- `s4-l1` 只讲日志、指标、追踪与告警；CDN/边缘缓存留在 s6-l4，采样实现细节不绑定厂商。
- `s4-perf` 只讲压测设计、指标解读、profile 与 Little 定律估算；不讲 Linux IO 内核（a8）与排队论完整数学（a7）。
- `s4-perf` 的容量估算方案题与 `p4-m2` 对齐：基线、两组场景、瓶颈证据、修复前后对比。
- Python 轨与 Node 题测试数量一致（各 7 条），错误类型按语言习惯使用 `RangeError` / `ValueError`。
