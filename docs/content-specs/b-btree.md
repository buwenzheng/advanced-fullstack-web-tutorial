## 1. 出口能力

1. 用页、扇出、树高解释索引查询的 IO 次数。
2. 区分聚簇索引与二级索引，理解回表。
3. 解释 LSM 的写放大、读放大、空间放大与 compaction。
4. 用树高/扇出估算给定数据量的索引层数。

## 2. 起点与误解

- 已经知道：索引能加速查询、EXPLAIN 看执行计划、分片解决单机容量。
- 常见误解：
  - 「索引越多越好」——写入放大与优化器选择成本。
  - 「B+tree 和 B-tree 一样」——B+tree 数据都在叶子，范围查询更友好。
  - 「LSM 写入快就没有代价」——compaction 带来读/写/空间放大。

## 3. 范围边界

- 本讲只讲：页与扇出、B+tree 插入/分裂/范围、聚簇与二级索引、LSM 三种放大。
- 不讲：SQL 索引设计教程与 EXPLAIN（`m2-index`）、分片与复制（`e1-datascale`）、存储引擎源码。
- 与相邻讲分工：b-btree 讲索引结构本身，核心课讲怎么用索引。

## 6. 练习

- 代码题：`createBPlusTree(order)`；`insert/search/range/height/keys`。
- 只做插入不做删除；叶子按键有序并用 next 串链；重复 key 忽略；`range(lo, hi)` 返回有序数组。
- 测试 ≥9：空树、单 key、根分裂、多层、范围、重复、顺序插入、乱序插入、keys 有序。
- Python：节点类 + bisect + 递归分裂；测试逐条对齐。

## 7. 事实与夹具

- 事实：B+tree 是常见索引结构但不是唯一；页大小与扇出因系统而异；LSM compaction 策略多样。
- 不新增夹具。
