## 1. 出口能力

1. 解释进程、文件描述符、连接数与打开文件上限的关系。
2. 区分阻塞、非阻塞、多路复用与 page cache 的作用。
3. 设计 Nginx 反向代理的关键配置：超时、重试、负载均衡、缓冲。
4. 识别 fd 耗尽、TIME_WAIT、长连接等常见故障。

## 2. 起点与误解

- 已经知道：容器能限制资源、反向代理能做入口、压测能发现瓶颈。
- 常见误解：
  - 「调大 ulimit 就解决了 fd 耗尽」——还要算 worker、连接与预留。
  - 「超时越长越安全」——超时叠加会放大故障恢复时间。
  - 「Nginx 每个连接一个线程」——多路复用才是高并发的基础。

## 3. 范围边界

- 本讲只讲：进程/线程/fd、IO 模型与 page cache、加权轮询、fd 预算、Nginx 关键配置与常见故障。
- 不讲：容器编排与发布流程（`m3-container`）、分布式锁（`e1-failures`）、内核源码与协议栈细节。
- 与相邻讲分工：b-linux 讲 Linux/IO 底座与反向代理，核心课讲容器、发布与分布式协作。

## 5. 概念检查

- C1 单选：文件描述符耗尽时最直接的现象。
- C2 多选：反向代理必须显式设置哪些超时。
- C3 单选：page cache 命中为什么能降低读延迟。

## 6. 练习

- 代码题：`createWeightedRoundRobin(servers)` 与 `checkFdBudget({...})`；测试 ≥8，覆盖权重比例、平滑顺序、健康跳过、全不健康、预算通过/不足、预留边界、非法参数。
- Python：纯函数/类实现；测试逐条对齐。
- 不设方案题。

## 7. 事实与夹具

- 事实：Nginx 配置项随版本变化；不同 OS 的 fd 上限不同；TIME_WAIT 与主动关闭方有关。
- 不新增夹具。
