## 1. 出口能力

1. 用 Little 定律把并发、吞吐、延迟连起来。
2. 用利用率与排队直觉解释 P99 为什么在接近饱和时非线性恶化。
3. 做平均、峰值、故障三场景的容量估算与冗余设计。
4. 画成本曲线，判断扩容与优化的优先级。

## 2. 起点与误解

- 已经知道：压测能测出单实例容量、扩容能提升吞吐、缓存能降低延迟。
- 常见误解：
  - 「平均 QPS 乘个系数就够了」——峰值、突发与故障降级场景不同。
  - 「利用率 90% 只是慢一点」——排队延迟在接近饱和时急剧放大。
  - 「扩容一定比优化便宜」——要看瓶颈是否可水平扩展、成本曲线是否线性。

## 3. 范围边界

- 本讲只讲：Little 定律、利用率与尾延迟、三场景估算、冗余、成本曲线、瓶颈迁移。
- 不讲：压测脚本与火焰图（`s4-perf`）、具体云厂商报价与实例选型、分片实现（`s5-data-scale`）。
- 与相邻讲分工：a1 讲「怎么算与怎么测」，a7 讲「怎么建模与估算」，s4-perf 讲「怎么压测与定位」。
