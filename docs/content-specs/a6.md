## 1. 出口能力

1. 解释布隆过滤器的误判率、位数组与哈希个数。
2. 实现布隆过滤器，准确表述「可能包含」与「一定不包含」。
3. 解释 HyperLogLog 的分桶、前导零、调和平均与误差。
4. 判断去重与计数场景该用精确结构还是概率结构。

## 2. 起点与误解

- 已经知道：缓存可以挡穿透、UV 需要去重计数、内存有上限。
- 常见误解：
  - 「布隆过滤器说存在就一定存在」——只保证不存在时一定不存在。
  - 「布隆过滤器可以删除元素」——标准实现置位共享，不能直接清位。
  - 「HLL 估算就是平均值」——用调和平均抑制大值影响，小基数误差更大。

## 3. 范围边界

- 本讲只讲：布隆位数组与误判率、HLL 分桶与估算、精确 vs 概率的取舍。
- 不讲：Redis 缓存与淘汰（`s3-l1`）、分片与复制（`s5-data-scale`）、计数布隆的完整实现。
- 与相邻讲分工：a6 讲概率结构本身，核心课讲缓存与容量策略。

## 5. 概念检查

- C1 单选：布隆过滤器返回 false 意味着什么。
- C2 多选：影响布隆误判率的因素。
- C3 单选：HLL 估算 100 万 UV，误差 2% 意味着什么。

## 6. 练习

- 代码题：`createBloomFilter({ bits, hashes })` 与 `createHLL(precision)`；测试 ≥8，覆盖加入必命中、未加入可能误判、误判率估算、不同哈希数、HLL 空集/小基数/大基数误差、重复元素。
- Python：位数组用 `bytearray`，注入哈希，测试逐条对齐。
- 方案题：短链去重与 UV 统计；自检清单覆盖规模、误判容忍、删除需求、内存预算、精确计数、降级、监控误差。

## 7. 事实与夹具

- 事实：布隆过滤器不支持标准删除；计数布隆可删除但有代价；HLL 误差约 1.04/√m；不同实现哈希方式不同。
- 不新增夹具。
