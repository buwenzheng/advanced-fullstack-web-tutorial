## 1. 出口能力

1. 用 Big-O 描述增长，先定义 n 与操作，再谈结论。
2. 识别微基准的五个陷阱：预热、计时精度、GC、死代码消除、环境噪声。
3. 用分位数与变异系数判断测量数据是否稳定。
4. 从操作计数拟合增长阶，区分 O(1)/O(log n)/O(n)/O(n log n)/O(n²)。

## 2. 起点与误解

- 已经知道：压测、P95/P99、火焰图的基本用法。
- 常见误解：
  - 「O(n) 一定比 O(n log n) 快」——忽略常数、缓存与数据规模。
  - 「跑一次就能下结论」——没有预热、重复与噪声控制。
  - 「平均值正常就没有问题」——尾延迟被平均值掩盖。

## 3. 范围边界

- 本讲只讲：增长阶、微基准方法、分位数与稳定性、增长拟合。
- 不讲：压测工具教程、火焰图与瓶颈定位（`s4-perf`）、容量建模（a7）。
- 与相邻讲分工：a1 讲「怎么算与怎么测」，a7 讲「怎么建模与估算」，`s4-perf` 讲「怎么压测与定位」。

## 5. 概念检查

- C1 单选：n 的定义不清晰时，复杂度结论为什么无效。
- C2 多选：微基准必须控制哪些变量。
- C3 单选：p99 高、均值正常说明什么。

## 6. 练习

- 代码题：`estimateGrowth(samples)` 增长拟合 + `summarizeBenchmark(samples)` 压测汇总。
- 测试 ≥8：常数、线性、线性对数、平方、点数不足、噪声、空样本、分位边界。
- Python：同一契约，`statistics` 可选，返回 dict。
- 固定噪声阈值 0.15；CV ≤ 0.1 视为稳定；分位用最近秩。

## 7. 事实与夹具

- 事实：Big-O 是渐近上界；实际性能受常数、缓存、GC 影响；分位数算法有差异。
- 不新增夹具，测试数据内联为纯常量。
