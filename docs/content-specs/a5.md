## 1. 出口能力

1. 实现固定容量环形缓冲，理解读写指针、满/空判定与覆盖写。
2. 实现 O(1) 的 LRU，理解哈希表 + 双向链表的组合。
3. 区分 LRU/LFU/TTL 的适用场景与失效模式。
4. 用固定内存缓冲做日志/指标背压，并说清丢弃策略。

## 2. 起点与误解

- 已经知道：缓存能降低读延迟、Redis 有淘汰策略、日志需要采集与上报。
- 常见误解：
  - 「LRU 用数组就行」——`splice`/`shift` 是 O(n)，高命中率下反而拖慢。
  - 「缓冲越大越好」——固定内存是约束，无上限缓冲会把故障变成 OOM。
  - 「LRU 对任何负载都有效」——扫描型负载会把热点全部淘汰。

## 3. 范围边界

- 本讲只讲：环形缓冲、LRU 结构、LRU/LFU/TTL 对比、缓冲背压与丢弃策略。
- 不讲：Redis 过期与淘汰配置（`s3-l1`）、日志/指标产品选型（`s4-l1`）、分布式缓存一致性。
- 与相邻讲分工：a5 讲内存结构与淘汰语义，核心课讲缓存产品与可观测性。
