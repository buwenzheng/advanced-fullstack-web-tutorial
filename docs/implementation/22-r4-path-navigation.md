## 1. 阶段边界

### 1.1 本阶段做

- **总览页**：四条路径卡片（A/B/C/D）+ 大块进度（主修/选修/工具箱分区）；弱化「STAGE 00–07 线性」叙事
- **侧栏**：按 block 分组；M2/M3/M4/B 显示章标题；E1 标「选修」；B 标「工具箱」
- **块页（原 StagePage）**：展示 kind、章、出口、项目入口、建议先修；路径 A 对 M3 提示「可只完成章1」
- **下一讲推荐**：`mastery` / next lesson 尊重「当前路径」或默认路径 C；不可用时回退「当前块内下一讲」
- **文案常量**：替换 LEDE / PATH_INTRO 等仍写「八个核心阶段」的句子
- **可选**：弱先修提示条（进入 M2 未完成 M1 时提示，不拦截）
- a11y：单一 h1、路径卡片可键盘操作、对比度不变差
- 包体：路径静态表进入口可接受；禁止把全文 catalog 打进主包

### 1.2 本阶段不做

- 不改 hash 路由形态（不加 `#/path/:id` 也可；若加，须同步 E2E，且旧链仍可用）
- 不改视觉以外的课程正文（R3 范围）
- 不在本阶段强制更新全部 21 张基线（记录 diff；R5 统一签字更新）
- 不引入新 UI 库

### 1.3 结束形态

- 新用户打开 `#/` 先看到路径，再看到大块
- 侧栏不再暗示必须 S0→S7 学完
- 报告页/搜索仍可用；链接指向新 ID（R2 已保证）
