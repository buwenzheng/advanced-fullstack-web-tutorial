# 批次任务卡模板

> 每个可执行任务一张卡。卡是给执行 Agent 的最小上下文单元：只读这张卡与卡里引用的文档，就能稳定完成。

## 任务卡

### T-<module>.<batch>.<n> <动作>

- **类型**：engine / spec / content / validation / review
- **依赖**：前置任务 ID 或评审门
- **输入**：
  - 大纲章节：`docs/curriculum-plan.md#...`
  - 模块 brief：`docs/implementation/...md#...`
  - 已有文件：
- **产出**：
  - 文件 1：
  - 文件 2：
- **约束**：
  - 只允许改：
  - 不允许改：
  - 不允许引入：
- **验收**：
  - 命令 1：`...`，预期：
  - 命令 2：`...`，预期：
  - 浏览器检查：
- **证据**：写入 `docs/reviews/...md` 的哪一节
- **回滚**：恢复哪个备份目录/文件
- **预计批量**：本任务涉及几讲/几个文件
- **停止条件**：出现什么情况必须停下来报告

## 批次收尾检查

- [ ] 本批所有课时 `status: 'ready'`；
- [ ] 单讲审计 0 错误；
- [ ] JS/Python/SQL 测试全过；
- [ ] starter 至少失败 1 条；
- [ ] 浏览器 0 控制台异常；
- [ ] 证据已写入 review 文件；
- [ ] 备份已更新；
- [ ] 下一批依赖已满足。
