- 302 表示临时跳转，301 表示永久跳转且可被浏览器长期缓存 — 2026-11-09 — 来源：RFC 9110；跳转接口默认用 302，除非确认目标永不改变。
- DNS TTL 不保证所有递归解析器严格遵守 — 2026-11-09 — 来源：RFC 1034/1035 与运营商实践；正文写「可能」不写绝对。
- 301 可被浏览器长期缓存 — 2026-11-09 — 来源：RFC 9110；跳转接口默认用 302，除非确认目标永不改变。
- 401/403/404/409/410/503 的语义 — 2026-11-09 — 来源：RFC 9110；401 未认证、403 已认证无权限、409 状态冲突、410 永久移除、503 暂时不可用可配合 Retry-After。

- 405 Method Not Allowed 响应应包含 Allow 头 — 2026-11-09 — 来源：RFC 9110。
- 400 Bad Request 表示请求语法或内容有问题；422 Unprocessable Content 语义来自 WebDAV — 2026-11-09 — 来源：RFC 9110、RFC 4918；400/422 的取舍由 API 契约固定。
- URI 百分号编码与解码规则 — 2026-11-09 — 来源：RFC 3986；非法编码的处理由实现决定，课程要求显式返回 400。
- Sunset 响应头用于声明资源弃用时间 — 2026-11-09 — 来源：RFC 8594。
- Deprecation 响应头用于标记弃用 — 2026-11-09 — 来源：RFC 9745。
- ISO 8601 日期时间格式 — 2026-11-09 — 来源：ISO 8601；正文用它表示时间字符串，不写死解析库行为。
- `Date.parse` 对非 ISO 格式的接受程度因 JavaScript 引擎而异 — 2026-11-09 — 来源：ECMAScript 规范与实现差异；课程契约只接受可解析的 ISO 字符串，并在测试中固定。

- 默认 CPython 构建存在 GIL，线程不能并行执行 Python 字节码；I/O 等待会释放 GIL — 2026-11-09 — 来源：Python 官方文档；自由线程构建取决于版本与构建选项。
- asyncio 是单线程协作式调度，适合 I/O 密集任务 — 2026-11-09 — 来源：Python 官方文档。
